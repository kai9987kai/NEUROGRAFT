FORECAST FIRST · THEN UPDATE COUNTS

How well did evidence predict?

No scored events

Average binary move/collision losses, scored before each supplied outcome. Lower is better. No events means no average.

The adaptive choice is a discounted predictive-score heuristic, not a posterior, confidence level or certified change detector. Beta(0.5, 0.5) smoothing scores forecasts only; replay uses actual integer counts and invents no edges. Guarded recent is a forecast-only comparison.
