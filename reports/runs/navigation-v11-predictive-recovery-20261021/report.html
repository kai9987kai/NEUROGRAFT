Predictive recovery study

Synthetic CPU navigation experiment with identical context_residual/predictive-head architecture in all four arms. Auxiliary weights are 0 and 0.5; the zero-weight predictor remains untrained. One collection round precedes all optimizer updates, giving exactly matched trajectories and minibatches within each collection-policy/initialization pair. Expert and recovery exposures intentionally differ. Recovery is a 50/50 teacher/learner mixture, not DART noise injection. All arms and model seeds are retained; checkpoint selection uses validation policy success, SPL and collisions only, retaining round zero on ties. Neither held-out test outcomes nor prediction probes select a candidate or arm. Raw policy tests disable teachers and learning. Full-map expert labels are privileged; the student receives local observation windows. Held-out prediction probes use one common frozen random-action corpus, report all feature groups and compare learned prediction with persistence and an explicit kinematic baseline. Prediction is an auxiliary representation objective, not rollout planning. Eight default test scenarios repeated across two model seeds are correlated, not sixteen independent episodes; no episode-level significance or confidence interval is claimed. Test seeds are disjoint from this study training/validation schedule, not certified absent from earlier source training. No checkpoint promotion, biological validation or connectome advantage is established. Hashes are local integrity receipts, not authenticity signatures. Optional replay checks frozen evaluation and prediction records in this CPU/runtime; training is not replayed.
