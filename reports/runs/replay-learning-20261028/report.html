Empirical replay learning study

Empirical tabular value learning on independent seeded synthetic grid/branch graphs. Schedules share identical experience and backup caps; actual backups may differ. The oracle solves only experienced transition counts, not unseen true geometry. Partial exposure is a shared shuffled history prefix, not an autonomous exploration policy. Goal relocation starts from identical warmed state; the planner should invalidate its old goal values. No neural weights are trained or promoted; these assays establish no biological equivalence or general navigation improvement. Timings are not included in deterministic evidence.

Protocol: 8 independent graph seeds; budgets [0, 4, 16, 64]. Agreement is measured only on states with a unique reference-best action. Curves start from the same state at each budget; they are not cumulative. Goal changes reset stale values, so identical fresh/relocated results can be expected.

Compare prioritized and uniform schedules at the same cap and inspect actual backups. Neither schedule is guaranteed to dominate. Raw histories, per-state values and decisive action traces are retained in report.json. Independent reference residuals must be below 1e-10.
